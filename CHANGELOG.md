# Changelog

All notable changes to Watcha will be documented in this file.

## [v0.1.0] - 2026-07-25

### Initial Release
- **Sleek Glassmorphism Design**: Frosted glass UI cards, custom top header, and floating bottom navigation bar.
- **Media Engine**: Full AndroidX Media3 ExoPlayer integration supporting MP4, MKV, AVI, FLV, WEBM, MOV, M4V, TS, MPEG, MP3, AAC, WAV, and FLAC.
- **Gesture Controls**: Double-tap seek (+10s / -10s), volume and brightness gestures, aspect ratio toggles, and sleep timer.
- **Local Persistence**: Room Database for MediaItems, Favorites, Watch Later, Playlists, and Watch History.
- **Customizable Theme**: Dark/Light mode toggle with adjustable glass intensity.
- **CI/CD Pipeline**: Automated GitHub Actions workflows for building APKs, running tests, and managing GitHub Releases.

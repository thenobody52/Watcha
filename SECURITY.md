# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Watcha, please report it directly to **Akik Forazi / FRAZIYM Soft** via email at `security@fraziym.com` instead of opening a public issue.

We will acknowledge receipt within 48 hours and work on a security fix.

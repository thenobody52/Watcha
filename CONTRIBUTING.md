# Contributing to Watcha

Thank you for your interest in contributing to Watcha!

## Code of Conduct

Please review our [Code of Conduct](CODE_OF_CONDUCT.md) before participating.

## How to Contribute

1. **Fork the Repository**: Create your own fork of `fraziym-soft/watcha`.
2. **Create a Feature Branch**: `git checkout -b feature/amazing-feature`.
3. **Commit Your Changes**: Follow clear commit messages (`feat: add double tap seek indicator`).
4. **Run Tests**: Ensure all unit tests pass with `./gradlew test`.
5. **Open a Pull Request**: Submit a PR to `main` using the Pull Request template.

## Developer Guidelines

- Follow official Kotlin & Jetpack Compose guidelines.
- Keep UI components reusable and accessible.
- Maintain test coverage for core business logic in ViewModels and Repositories.

For architectural details, see [docs/Architecture.md](docs/Architecture.md).

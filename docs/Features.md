# Watcha Feature List

## Supported Formats
- **Video:** MP4, MKV, AVI, FLV, WEBM, MOV, M4V, TS, MPEG
- **Audio:** MP3, AAC, WAV, FLAC

## Core Features
1. **Glassmorphism UI:** Translucent frosted glass cards, customizable blur intensity, floating navigation bar.
2. **Hardware Acceleration:** Hardware & software decoding toggle in settings.
3. **Playback Control:** Play, pause, double tap seek (+10s / -10s), playback speed (0.25x - 2.0x), aspect ratio toggles (Fit, Crop, Stretch, Fill).
4. **Sleep Timer:** Automatic playback termination timer (15m, 30m, 45m, 60m).
5. **Picture-in-Picture:** Floating video player mode when backgrounding the app.
6. **Library Management:** Automatic MediaStore scanner, folder browser, filtering by format extension.
7. **Playlists & History:** Bookmarked favorites, watch later lists, custom playlists creation, and watch history records.
